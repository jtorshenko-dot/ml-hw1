# ML Homework 1

Проект, посвящённый базовой работе с табличными данными и визуализацией в Python в рамках курса по машинному обучению. В работе используются pandas, numpy, matplotlib и seaborn для анализа данных, построения графиков и решения прикладных задач на основе реального датасета.

Ноутбук показывает основы работы в Jupyter, обработку таблиц с помощью pandas, визуальный анализ данных и задачу распределения студентов по курсам на основе заданных признаков и предпочтений. Используются базовые навыки data analysis, exploratory data analysis и подготовки данных для дальнейших ML-задач.
